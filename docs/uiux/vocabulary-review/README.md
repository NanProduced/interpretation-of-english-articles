# 生词本复习功能设计稿

> 当前版本方向：生词本仍作为“我的生词本”二级入口，不新增底部 Tab；复习功能先做“记忆曲线提醒 + 卡片浏览 + 手动标记”，不做选择题、拼写题或释义匹配。

## UX 决策

- 生词本页面只保留 `待复习 / 全部` 作为主切换；更多筛选收进右侧筛选入口或后续 bottom sheet。
- 复习不是测验。每张卡片直接展示词、释义和来源语境。
- 复习页底部只提供 `还不熟` / `已掌握` 两个动作。
- 复习卡片支持 `语境 / 词典` 两个视图，优先用 tab 实现；横向滑动可作为增强交互。
- 复习完成后展示本次数量、已掌握、仍需巩固、下次提醒，并允许返回生词本或继续阅读。
- 结果页阅读流不新增强打断提醒；已保存词标记维持轻量。
