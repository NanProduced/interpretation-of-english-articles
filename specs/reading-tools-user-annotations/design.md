# Design

## Design Language

参考方向是“轻质纸张阅读器”，不是工具软件：

- 背景：warm paper、pure white、pale sage 三种低噪声阅读底。
- 文字：英文正文最高权重，译文次级，工具层再后置。
- 浮层：白色或轻纸色，圆角克制，阴影极轻，像纸页上浮起的小托盘。
- 图标：使用 lucide 风格线性图标，线宽统一，不用 emoji。
- 颜色：用户批注使用淡绿、淡蓝、淡紫三色，饱和度低；黄色保留给系统词汇高亮，避免用户批注和 AI 标注混淆。

## Visual Separation

AI 标注：

- 来源于系统解析。
- 使用细下划线、语法卡、术语卡、句式卡。
- 视觉像“阅读助手的铅笔线”。

用户批注：

- 来源于用户主动选择。
- 使用淡色高亮、页边小标记、句后小纸条。
- 视觉像“私人读书笔记”。

两者不能共用同一高亮色。用户高亮默认用非常淡的 soft green；词汇高亮使用克制黄色，短语使用淡紫色，语法/上下文/学术标注以细线系统表达。

## Reading Settings Sheet

入口：

- 顶部更多菜单内：`阅读设置`
- 或阅读页底部轻量工具层中的 `Aa`

布局：

- bottom sheet，高度约 36%-44% 屏幕，根据安全区和内容自然收敛。
- 不使用多 tab；打开后展示单页阅读控制台，让纸面、字号、行距、译文一屏可见。
- 不在 sheet 内放示例预览区；设置变化直接作用到背后的解析页真实内容。
- 菜单拉起时不模糊页面，只使用轻遮罩，保留真实页面变化的可见性。
- 设置区使用轻量行分组，不使用卡片嵌套。

控件：

- 字号：四档 segmented control，使用 `A` 大小变化表达。
- 行距：三档 segmented control，同时影响正文行高、句子间距和译文间距。
- 译文显示：隐藏 / 淡显 / 标准。
- 背景：三个圆形色块配短标签。

## Selection Toolbar

小程序首版不依赖系统拖选浮层，而采用 Claread 自定义长按工具栏：

- 用户长按英文句子或中文译文。
- 当前句子进入克制的临时选中态；长按译文时同样选中对应英文句子。
- 底部浮出固定工具条，避免依赖文本 rect 定位。
- 不显示拖拽手柄，不支持任意范围拖选。
- 段落级选择不属于首版范围。

工具条项目：

- 笔记
- 复制
- 收藏
- 反馈

不提供 `解释` 或 `查词` 入口；单词查词继续使用正文点按单词交互。

## Note Sheet

用户点击“笔记”后：

- bottom sheet 高度约 42%-55%。
- 顶部显示选中句子，最多 3 行。
- 下方为笔记输入区域。
- 可选高亮颜色：淡绿 / 淡蓝 / 淡紫。
- 主按钮：保存笔记。
- 次按钮：仅高亮。

保存后：

- 正文中显示用户高亮。
- 句末显示轻量 note dot 或边注短线。
- 点击 note dot 打开笔记详情。

## Favorites

收藏不单独做大浮层：

- 工具栏点击收藏后即时完成。
- 已收藏句子在正文右侧或句末显示轻书签标记。
- 收藏列表使用“我的摘录”入口，首版展示 `sentence` target type，并按文章归组、按句序排序。

## My Excerpts

定位：

- “我的摘录”是学习复习面板，不是简单书签导航。
- 页面默认按文章分组展示，每个文章组下展示用户留下资产的句子。
- 顶部筛选为 `全部 / 收藏 / 高亮 / 笔记 / 解析`，不展示统计 chip。

文章组：

- 标题优先使用解析记录中的中文概括标题；缺失时降级为英文标题或原文首句截断。
- 标题下方显示英文摘要/首句作为辅助线索。
- 右侧以小胶囊显示当前筛选下的句子数量。

句子卡：

- 合并同一句子的收藏、高亮、笔记状态，使用轻量标签表达，不重复展示多张卡。
- 原文使用正文 serif 风格，但字号和行高低于解析页正文，避免列表过重。
- 译文使用灰色正文，保持复习可读性。
- 用户笔记使用浅纸色内嵌条，作为个人记忆线索。
- 语法和句子解析放在 `复习要点` 区块内完整展示；使用小标签区分 `语法` / `句析`，不使用解析页的大卡片样式。
- 在 `全部` 筛选中也必须完整展示该句已有解析要点；不能只在 `解析` 筛选中展示完整内容。

跳转：

- 点击句子卡可回到对应解析记录。
- 目标句高亮可作为当前实现保留；精确滚动定位暂不作为本阶段验收项。

## Motion

- 工具栏出现：150-220ms opacity + translateY。
- 设置 sheet：使用已有 bottom sheet 进入节奏。
- 保存笔记：按钮轻微 scale/opacity，不使用跳动动画。
- 高亮落下：淡色背景 180ms fade-in。
