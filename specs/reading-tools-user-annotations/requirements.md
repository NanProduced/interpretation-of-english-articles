# Requirements

## Background

Claread 的标注系统已经完成，下一步需要补齐阅读中的用户主动操作能力：调整阅读体验、复制文本、收藏句段、写个人笔记。这个能力不属于 AI 解析系统，而是用户自己的阅读痕迹系统。

当前痛点：

- 解析页内不能稳定复制原文/译文。
- 收藏目前偏向全文记录，缺少句子/段落级收藏体验。
- 用户看到重要句子或难句时，不能留下自己的笔记。
- 字号、行距、背景、译文显示等长期阅读偏好没有独立配置。

## Goals

1. 提供轻量阅读设置抽屉，让用户能调整阅读舒适度。
2. 提供长按句子、译文或段落后的阅读工具栏，支持复制、收藏、笔记和反馈。
3. 建立用户自行批注系统，支持高亮、笔记、收藏、删除、列表查询。
4. 新增后端表保存用户批注；阅读设置保存到用户 profile 配置中。
5. 保持 Claread 的纸感、安静、阅读优先风格。

## Non-goals

- 不做完整电子书系统，不做章节目录、进度条、翻页模式。
- 不做多用户共享笔记、公开评论、社交化批注。
- 不做复杂标签系统；首版只保留轻量颜色和笔记文本。
- 不改 workflow schema，不改变 AI 标注生成逻辑。
- 不让用户批注参与 AI 解析结果投影。

## Feature Scope

### Reading Settings

首版设置项：

- 字号：小 / 标准 / 大 / 特大
- 行距：紧凑 / 标准 / 宽松
- 译文显示：隐藏 / 淡显 / 标准
- 背景：纸张 / 纯白 / 护眼

暂不做：

- 自定义字体下载
- 夜间模式
- 亮度控制
- 滚动/翻页模式

字体说明：

- 首版不暴露多字体选择。
- 先保证当前正文 serif 风格、中文译文、标注定位稳定。
- 后续再考虑 `默认 / 经典阅读` 两档字体。

### Reading Toolbar

触发方式：

- 小程序首版：长按句子、译文或段落。
- 不使用微信原生文本拖选，不显示拖拽手柄，不做任意范围选区。
- 单词查词继续沿用现有点按单词交互，不接入长按句子工具栏。

工具项：

- 复制：复制原文、译文或双语。
- 收藏：收藏当前句子/段落。
- 笔记：打开个人笔记 sheet。
- 反馈：沿用现有反馈系统，自动带上上下文。
- 句子反馈使用 `feedback_scope='sentence'`，`target_id` 使用同一套句子 target key；有云端 `analysis_record_id` 时带 UUID，没有云端记录时只带 context snapshot。
- 不提供解释入口；句子含义优先通过已有译文和解析卡片承载。

### User Annotation

用户批注类型：

- highlight：仅高亮，无笔记。
- note：高亮 + 用户笔记。
- bookmark：句子/段落收藏，可复用 favorite_records。

用户高亮颜色：

- soft_green / soft_blue / soft_purple。
- warm_yellow / sage_green 仅作为历史数据兼容，不再作为新建选项。

锚点策略：

- 首版使用稳定句子/段落锚点：`record_id + paragraph_id + sentence_id`。
- `text_range`、`start_offset`、`end_offset`、`text_hash` 仅作为后端兼容和未来增强字段，小程序首版不使用。
- 渲染时以 sentence_id 或 paragraph_id 为准；如果文本版本变化导致锚点不可靠，则降级为句后笔记入口，不强行错误高亮。

## Success Criteria

- 用户能在解析页内复制原文、译文和双语。
- 用户能收藏当前句子/段落，并在历史/收藏入口看到。
- 用户能给句子/段落写笔记，重新进入文章后笔记仍能显示。
- 阅读设置保存后跨页面、跨会话生效。
- 设置调整不会破坏 AI 标注、词卡定位、句子同步高亮。
- 用户批注视觉上明显不同于 AI 标注，但不抢正文。
